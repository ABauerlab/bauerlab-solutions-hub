# BauerLab — bauerlab-solutions-hub

Site institucional da BauerLab (bauerlab.com.br).

## Stack

- Next.js (App Router), exportação estática (`output: "export"`)
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Framer Motion

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```

Gera o site estático em `out/`, pronto para publicar em qualquer hospedagem de arquivos estáticos.
